# ゾイド3D制作 知識ベース

このフォルダは、**今後ゾイドを作る 3D エージェント(AI)の判断材料**。
コマンドウルフの制作で「何を決め、なぜそうし、どう確かめ、どうなったか」を、種類を問わず使える形で残す。

## 読む順
| # | 文書 | 使う場面 |
|---|---|---|
| 01 | [制作パイプラインの基本](01_pipeline.md) | 新しいゾイドを始めるとき。工程と、各工程の「完了の条件」 |
| 02 | [設計で決めること](02_design_decisions.md) | 作り始める前。後から変えると高くつく決定の一覧 |
| 03 | [リグのパターン(体型別)](03_rig_patterns.md) | 骨組みを決めるとき。狼以外(獅子・恐竜・鳥・多脚…)への応用 |
| 04 | [動きの仮説と検証の記録](04_motion_hypotheses.md) | 「それっぽい動き」を作るとき。何が効き、何が効かなかったか |
| 05 | [外部AIへの引き渡し](05_handoff.md) | 仕上げのメッシュ・質感を外部AIへ渡すとき |

## コードとの対応
- 共通部品: `src/zoidkit/`（脚IK・歩容・リグ生成・検査）… 種類に依存しない
- 種類ごと: `src/species/command_wolf.py`（骨の位置・部品・胴の動き・歩容の数値）
- 新しいゾイドは `src/species/<名前>.py` を足すだけで、zoidkit はそのまま使う

## 運用ルール
- 判断を変えたら、02 の表と 04 の記録を更新する（「なぜ」を消さない。取り消し線で残す）
- 区切りごとに `docs/opus_review_request.md` の手順で評価し、`docs/review_v*.md` に残す
