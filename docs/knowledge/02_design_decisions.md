# 02 設計で決めること

作り始める前に決める。**後から変えるほど高くつく順**に並べた。
右の列はコマンドウルフでの答え。新しいゾイドでは同じ表を埋めてから始める。

## A. 変えると全部やり直しになるもの
| 決めること | 選択肢 | コマンドウルフ | 理由 |
|---|---|---|---|
| 座標系と単位 | Y前/Z上、m | +Y 前、+Z 上、m | Blender の骨(ローカルY)と揃う |
| 体型 | 四足 / 二足 / 鳥 / 多脚 / 蛇 / 甲殻 | 四足 | 03 のどのパターンを使うか決まる |
| 足の着き方 | 趾行性(つま先立ち) / 蹠行性(足裏全体) / 蹄行性 | 趾行性 | 脚の骨の本数と、かかとの動きが変わる |
| スケール | 実寸 / 模型比 | 全長約6m、背の高さ約2m | 速度・歩幅・重力の見え方の基準 |
| 骨の親子の幹 | root → 骨盤 → 背骨 → 胸 → 首 … | root → body(骨盤) → chest(胸) → neck → head | 背骨を2本以上にしないと、走りで背がしならない |
| 部品と骨の対応 | 1部品=1骨(剛体) / ウェイトで曲げる | 1部品=1骨 | メカは曲がる皮がない。関節は円柱で隠す |

## B. 変えるとリグとアニメをやり直すもの
| 決めること | 選択肢 | コマンドウルフ | 理由 |
|---|---|---|---|
| 関節の位置 | ― | 股関節 z1.38、膝・足首は IK で決定 | 見た目の回転中心と一致させる。ずれると部品が外れて見える |
| 脚の節の数 | 2節 / 3節 / 4節(+指) | 肩甲骨(前のみ) + 大腿 + すね + 中足 + 指 | 3節+指が犬・猫の最小構成 |
| リグの方式 | 全部焼き込み / IK コントロール / 組み合わせ | 組み合わせ | コードで再生成でき、GUI で足だけ手直しできる |
| コントロール骨 | IK ターゲット、ポール、ルート | IK_脚、POLE_脚、root | 「掴んで動かす骨」と「変形する骨」を分ける |
| 可動部の制約 | 角度制限、Damped Track、Stretch To | ダンパーは Damped Track(伸縮しない) | 実物の油圧シリンダーと同じく、筒とロッドの重なりで伸びる |
| 骨の名前 | ― | `FL_thigh`、`IK_FL`、`FL_d1_cyl` | 左右・前後・部位・役割が名前で分かる |

## C. 何度でも調整できるもの(ただし記録は残す)
| 決めること | コマンドウルフ |
|---|---|
| 歩容の種類 | トロット、ギャロップ(+進行方向で横・斜め) |
| 速度・周期・接地率 | 04 と `species/command_wolf.py` の `GAITS` |
| 胴・首・尾の揺れ | `_gallop_motion`、`pose_frame` |
| 色・材質 | `COL` |

## 判断のコツ
- 迷ったら「**動きのために必要か**」で決める。動きに関係しない形は後回しでよい
- 骨は多めに作ってもよい(使わなければ動かさないだけ)。**足りない骨は後から足すと親子が崩れる**
- 数値の妥当性は検査で確かめる(例: 歩幅が脚の届く範囲を超えると足が滑る → 伸びきり回数を数える)
