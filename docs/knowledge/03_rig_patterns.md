# 03 リグのパターン（体型別）

コマンドウルフで作った部品(`zoidkit`)が、他の体型にどう当てはまるかの対応表。
「実装済み」は動作確認済み、「応用」は同じ部品の組み替えで作れる見込み、「新規」は新しい部品が要るもの。

## 共通の部品（体型を問わない）
| 部品 | 中身 | 状態 |
|---|---|---|
| 背骨の分割 | 骨盤(body) と 胸(chest) の2本。走りでしならせる | 実装済み |
| 脚チェーン | [肩甲骨] → 大腿 → すね → 中足 → 指。`LegSpec` で定義 | 実装済み |
| 脚 IK | すねに IK(chain 2) + ポール。足は IK ターゲットの回転をコピー | 実装済み |
| 足の軌道 | 接地点(指の付け根)を主役に、接地・蹴り出し・振り出し | 実装済み |
| ダンパー | 筒とロッドが互いを向く(Damped Track) | 実装済み |
| 首の安定化 | 胴の傾きを首で打ち消し、頭を水平に保つ | 実装済み |
| あご | 頭の子。開閉の回転1軸 | 実装済み |
| 砲塔 | 胴の子。旋回(Z) と 俯仰(X) | 1骨で実装済み。旋回台と砲身の2骨へ分けるのが次 |
| 尾 | 2〜3節の連鎖。遅れて付いてくる | 実装済み(2節) |
| キャノピー | 頭の子。後ろ端のヒンジで開閉 | 新規(次の作業) |

## 体型別
| 体型 | ゾイドの例 | 脚 | 使い方 | 状態 |
|---|---|---|---|---|
| 四足・趾行性(犬・猫) | コマンドウルフ、シールドライガー、セイバータイガー | 4本、前脚に肩甲骨 | そのまま | 実装済み |
| 四足・重量級(象・恐竜) | ゴルドス、マンモス、アイアンコング(ゴリラ) | 4本、蹠行性に近い | 中足を短く・ほぼ垂直、duty を高く(0.6〜0.75)、歩きのみ | 応用 |
| 二足・獣脚類(肉食恐竜) | ゴジュラス、ジェノザウラー、レブラプター | 2本、逆関節 | `LegSpec` を2本。尾と頭でバランスを取る(重心を脚の上に保つ)。胴の左右揺れ(ロール)が必須 | 応用 + 重心制御は新規 |
| 鳥・翼 | レイノス、ストームソーダー、サラマンダー | 2本 + 翼 | 翼は腕の3節チェーン + 羽ばたき周期。脚は着地時のみ | 新規(翼) |
| 多脚(虫・甲殻) | ガイサック(サソリ)、グランチュラ(クモ) | 6〜8本 | `LegSpec` を本数分。歩容は三脚歩行(交互に3本ずつ接地) | 応用 |
| 亀 | カノントータス | 4本、横に張り出す | 膝を外へ曲げる(ポールを横に置く)。遅い歩きのみ | 応用 |
| 蛇 | (デススティンガーの尾など) | なし | 背骨を多節化し、波を後ろへ送る | 新規 |

## 脚の定義で変える値（`LegSpec`）
| 値 | 意味 | 犬型 | 重量級 | 二足恐竜 |
|---|---|---|---|---|
| bend | 膝の曲がる向き | 前脚 -1 / 後脚 +1 | 前脚 -1 / 後脚 +1 | +1 |
| l1, l2 | 大腿・すねの長さ | 同じくらい | 大腿が長い | すねが長い |
| toe | 足首→指の付け根 | 前下がり(つま先立ち) | ほぼ真下(短い) | 前下がり(長い) |
| scapula | 肩甲骨 | 前脚にあり | 前脚にあり(小さく振る) | なし |
| ankle_z | 足首の高さ | 0.30 | 0.1〜0.2 | 高い |

## 歩容の早見表（`Gait`）
| 歩容 | 位相(脚ごとのずれ) | duty | 使う体型 |
|---|---|---|---|
| 歩き(walk) | 後左0 → 前左0.25 → 後右0.5 → 前右0.75 | 0.6〜0.75 | 全四足。重量級はこれだけ |
| トロット | 対角が同時(0 / 0.5) | 0.5 | 犬型の中速 |
| ギャロップ | 後右0 → 後左0.1 → 前左0.45 → 前右0.55 | 0.3〜0.4 | 犬型・猫型の高速 |
| 二足の走り | 左0 / 右0.5 | 0.3〜0.4 | 恐竜型 |
| 三脚歩行 | 3本ずつ交互(0 / 0.5) | 0.5〜0.6 | 6脚 |

## 応用するときの手順
1. 02 の表を埋める(体型・足の着き方・スケール)
2. `src/species/<名前>.py` を作り、`LEGS`・`P`(胴・首・尾の関節)・`GAITS`・部品を書く
3. `build_demo.py` の import を差し替えて生成 → `check_motion.py` で検査
4. 04 に仮説と結果を追記
