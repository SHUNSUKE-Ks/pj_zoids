# 05 外部AIへの引き渡し

目標: **形の塊・骨・動きまでを Blender で仕上げ、細部の造形と質感だけを外部AIに任せる。**
外部AIに渡した後でも、骨と動きはこちらのものをそのまま使えることを条件にする。

## 引き渡しの条件（チェックリスト）
- [ ] 部品が骨ごとに分かれている(1部品=1骨、名前 `<骨>_<材質>`)
- [ ] 各部品のピボット(回転中心)が骨の根元と一致している
- [ ] 関節は円柱などで隠れていて、動かしても隙間が見えない
- [ ] `check_motion.py` が全歩容で OK
- [ ] 4面図・歩行のコマ割り・動画が最新
- [ ] 骨の一覧と親子関係、コントロール骨の説明がある(`docs/rigging_guide.md`)
- [ ] 部品ごとの「形の指示」(参考画像のどこに当たるか、残すべきシルエット)がある

## 渡し方の候補
| 方法 | 外部AIに頼むこと | 戻し方 |
|---|---|---|
| 部品ごとに渡す | 「この塊(プロキシ)を、この参考画像の部品の形に作り込む」 | 同じ名前・同じピボットで差し替え |
| 全身の参考を作らせる | 画像から全身モデルを生成(Hunyuan3D など) | 形の参考として見るだけ。部品には使わない |
| 質感だけ | テクスチャ・汚し | 材質を差し替え |

**推奨は「部品ごと」**。全身の一体モデルはリグに載らない(関節で切ると断面に穴、回すと隙間)。

## 書き出し
- 形式: `.glb`(アニメーション込み)、または `.fbx`
- プロキシの `.blend` と、再生成用のコード一式(`src/`)を一緒に渡す
- 書き出しスクリプトは未作成(次の段階で `src/export.py`)
