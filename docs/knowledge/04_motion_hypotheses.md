# 04 動きの仮説と検証の記録

「動きがそれっぽく見える」ための演出を、**仮説 → 判断 → 評価 → 結果** で残す。
評価の方法: 自動検査(`check_motion.py`)、歩行のコマ割り(`gait_sheet.py`)、4面図と参考画像の比較、動画の目視。

状態: ✅ 効いた / 🟡 入れたが目視の評価待ち / ❌ 効かなかった / ⏳ 未着手

## 「それっぽさ」の4要素（仮の枠組み）
1. **接地** … 足が地面に吸い付いている(滑らない・めり込まない)。崩れると一瞬で嘘に見える
2. **重さ** … 胴が沈み、脚が体重を受ける。胴が高く脚が細いと軽く見える
3. **タイミング** … 足の順番と、胴・首・尾の遅れ(オーバーラップ)
4. **シルエット** … 走りの各瞬間で、真横から見て形が読めるか

---

## 記録

### H1 足を地面に固定すれば、滑らない ✅
- 仮説: 接地中の足を「胴体に対して進行速度で後ろへ流す」と、世界から見て止まる
- 判断: 足の位置を本体からの相対で作り、本体は一定速度で進める
- 評価: `check_motion.py` で接地中の足の水平速度を測る
- 結果: 全脚 0.000 m/s(トロット・ギャロップ・横・斜めすべて)。**最初に作るべき土台**

### H2 歩幅が脚の届く範囲を超えると、足が滑る ✅
- 仮説: 脚が伸びきると IK が足の目標に届かず、足が流れる
- 判断: 伸びきりの回数を数えて表示。脚を短くしたとき速度・周期を合わせる
- 結果: 脚を 0.85→0.80m にしたとき 15回 → 速度 8.0→7.5m/s、周期 18→16 で 0回
- 教訓: **歩幅 = 速度 × 接地率 × 周期秒**。脚の長さを変えたら必ず見直す

### H3 対角トロットは機械的に見え、「駆けている」感が出ない ✅
- 仮説: 狼の疾走らしさは、足がばらばらに着地し、全部の足が浮く瞬間にある
- 判断: ロータリー・ギャロップ(後右→後左→前左→前右、接地率 0.35)
- 結果: コマ割りで浮遊期が見え、駆け足らしくなった。トロットは横ステップ用に残す

### H4 背骨がしならないと、走りが硬い ✅
- 仮説: 脚を集める時に背が丸まり、伸ばす時に反るのが疾走の核
- 判断: 背骨を body と chest の2本に分け、ギャロップの周期で曲げる(±0.14rad)
- 結果: 前半身と後半身が別々に動き、伸び縮みが見えるようになった

### H5 胴が高く脚が細いと、テーブル脚のロボットに見える ✅
- 仮説: 重さの印象は「腹から地面までの高さ ÷ 胴の厚み」と脚の太さで決まる
- 判断: 比率を 1.6 → 1.0 に、脚の太さを約1.5倍、脚を胴の真下へ
- 結果: 4面図で参考画像に近づいた(`docs/img/v2_step1-3_check.jpg`)
- 教訓: **動きの評価より先に、プロポーションを合わせる**

### H6 頭を水平に保つと、疾走の意志(獲物を見据える)が出る 🟡
- 仮説: 狼は走るとき頭を低く、ほぼ一定の高さに保つ。胴と一緒に頭が揺れると「ぎこちない機械」に見える
- 判断: 首で胴の傾き(ピッチ+背の曲げ)の 90% を打ち消す。頭の上下の揺れを 1/3 に
- 評価待ち: 動画で頭の軌道を見る。安定させすぎると「頭だけ別撮り」に見える恐れ → 打ち消し率 70〜90% で比較

### H7 肩甲骨が動くと、前脚の踏み出しが伸びる 🟡
- 仮説: 四足の前脚は肩ごと前後にスライドする。これがないと前脚が短く、ちょこちょこ歩きに見える
- 判断: 前脚に肩甲骨の骨を追加。足が前にあるほど前へ(ギャロップ ±0.22rad)。赤い肩装甲も一緒に動く
- 評価待ち: 振り幅 0.22 が大きすぎないか(装甲が胴にめり込まないか)

### H8 足首から先が一枚板だと、蹴り出しと着地が嘘っぽい 🟡
- 仮説: 接地の終わりに「指の付け根を支点にかかとが上がる」、遊脚の前半に「足先がたたまれる」と、力強く地面を押して見える
- 判断: 指の骨を追加。接地中は指を地面に平らに保ち、終盤 35% でかかとを 0.45rad 上げる。遊脚で指を丸める
- 評価: 足滑り検査は OK(かかとを上げても接地点は動かない)。見た目は評価待ち

### H9 ダンパーは伸縮より「重なりが変わる」方がメカらしい 🟡
- 仮説: 筒ごと引き伸ばすとゴムのように見える。実物は筒とロッドが滑り合う
- 判断: Stretch To(伸縮)をやめ、Damped Track(向きだけ合わせる)にして、筒とロッドを 65% ずつの長さで重ねる
- 評価待ち: 脚を伸ばしきったとき、筒とロッドの間に隙間が出ないか

### H10 尾は横に振るより、後ろへ流す方が速く見える 🟡
- 仮説: 高速時の尾は舵(かじ)として後方に伸びる。大きく振ると遅く見える
- 判断: 横の振りを 1/3 に、胴のピッチに逆らって水平を保つ
- 評価待ち

## 未着手の仮説 ⏳
- H11 着地の瞬間に胴が一瞬沈む(衝撃の吸収)と重さが出る
- H12 歩容の切り替え(トロット→ギャロップ)は、周期を先に変えてから位相を移すと自然
- H13 横ステップでは胴を進行方向へ 5〜8° 傾けると踏ん張って見える
- H14 走りながら斜めに跳ぶときは、踏み切る後脚を深く曲げる「ため」が要る
- H15 重量級ゾイドは duty を上げ、胴の上下を小さく・遅くすると大きく見える(スケール感)
